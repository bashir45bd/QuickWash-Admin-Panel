# 🧺 QuickWash Admin Panel

The **QuickWash Admin Panel** is a web-based management system designed to control and monitor all backend operations of the **QuickWash Laundry Service Application**.
It allows administrators to efficiently manage users, services, categories, items, orders, payments, promo codes, and customer reviews through a secure dashboard.

---

## 🚀 Features

### 🔐 Authentication

* Admin login with secure credentials
* Session-based access control

### 👥 User Management

* View registered users
* Manage user profiles and verification status

### 🛠 Service Management

* Add, update, and delete laundry services
* Control service availability

### 🗂 Category Management

* Create and manage service categories
* Upload and update category images

### 🧺 Item Management

* Manage items based on services and categories
* Set item price, image, and details

### 📦 Order Management

* View all user orders
* Track order status (Pending, Paid, Delivered)
* View order items and customer details

### 💳 Payment Tracking

* Monitor payment status
* Store transaction and payment method details

### 🎟 Promo Code Management

* Create and manage promo codes
* Set discount percentage and status

### ⭐ Review Management

* View customer ratings and reviews
* Monitor service feedback

### 📊 Dashboard

* Total users count
* Today’s orders
* Revenue summary
* Recent orders overview

## ⚙️ Installation & Setup

1. Clone the repository

   ```bash
   git clone https://github.com/your-username/QuickWash-Admin-Panel.git
   ```

2. Move the project to XAMPP `htdocs` folder

3. Import the database

   * Open **phpMyAdmin**
   * Create a database
   * Import the provided `.sql` file

4. Configure database connection

   * Update database credentials in `config.php`

5. Run the project

   * Start Apache & MySQL
   * Open browser and visit:

     ```
     http://localhost/QuickWash-Admin-Panel
     ```
